# 🧹 Sistema de Gestão de Escalas de Limpeza

Sistema web desenvolvido para auxiliar na **organização, registro e controle das escalas de limpeza de uma igreja**.

O projeto foi desenvolvido como parte de um **Projeto de Extensão Web Standards** do curso de **Ciência da Computação** do Centro Universitário ENIAC.

## 📖 Sobre o Projeto

A ideia surgiu a partir da necessidade de substituir métodos manuais utilizados para organizar as equipes responsáveis pela limpeza da igreja, como listas em papel, anotações em cadernos e mensagens em grupos.

O sistema centraliza essas informações em uma aplicação web, facilitando o cadastro dos membros, a organização das equipes, o controle das datas e o registro das atividades realizadas.

## 🎯 Objetivo

O principal objetivo do projeto é tornar o processo de organização das escalas de limpeza **mais eficiente, transparente e acessível** para os responsáveis e membros envolvidos.

### Objetivos específicos

* Cadastrar membros e voluntários;
* Organizar as equipes responsáveis pela limpeza;
* Registrar datas e atividades;
* Controlar a presença dos participantes;
* Registrar observações sobre as atividades;
* Consultar as escalas programadas;
* Armazenar os dados em um banco de dados;
* Reduzir a utilização de registros em papel;
* Melhorar a divisão das tarefas entre os membros.

## ⚙️ Funcionalidades

* 👤 Cadastro de membros;
* 📅 Cadastro de datas de limpeza;
* 👥 Definição das equipes responsáveis;
* ✅ Registro de presença;
* 📝 Registro de observações;
* 📋 Visualização das escalas programadas;
* 🗄️ Armazenamento das informações no banco de dados.

## 🛠️ Tecnologias Utilizadas

* **HTML5** — estrutura das páginas;
* **CSS3** — estilização e interface;
* **JSP** — desenvolvimento da aplicação web;
* **MySQL** — banco de dados.

## 🗄️ Banco de Dados

O sistema utiliza o **MySQL** para armazenar as informações relacionadas aos membros, equipes, escalas e registros das atividades.

A utilização de um banco de dados permite centralizar as informações e facilitar o acesso e gerenciamento dos registros.

## 🚀 Como Executar o Projeto

### 1. Pré-requisitos

Antes de executar o projeto, é necessário possuir um ambiente compatível com:

* Java;
* Apache Tomcat;
* MySQL;
* IDE compatível com projetos Java/JSP.

### 2. Banco de Dados

1. Abra o MySQL;
2. Crie o banco de dados utilizado pelo projeto;
3. Execute o script SQL disponibilizado no repositório;
4. Configure as credenciais de acesso ao banco na aplicação.

### 3. Aplicação

1. Clone este repositório;
2. Abra o projeto na sua IDE;
3. Configure o servidor Apache Tomcat;
4. Verifique a conexão com o MySQL;
5. Execute a aplicação.
